This repository showcases a collection of embedded systems and IoT projects built using ESP32, Arduino, and various sensor-based automation techniques. The work includes UART- and OTA-based ESP32 firmware uploading, PID-controlled systems, LiDAR-assisted cruise control, and smart-home automation using DHT22, LDR, PIR, IR sensing, and capacitive water-level measurement. Additional modules include web-dashboard integration, image-based monitoring, real-time alerts, and wireless communication features. Together, these projects demonstrate practical applications in electronics, control systems, and IoT development with optimized code and system-level testing. This repository contains the hardware side firmware alone.
